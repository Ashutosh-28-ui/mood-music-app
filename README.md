#  Mood Music App

A web app that recommends songs based on user mood using Spotify API.

##  Features

* Mood-based song search (happy, sad, chill, etc.)
* Spotify integration
* Song preview playback
* Add songs to favorites
* Clean and responsive UI

##  Tech Stack

* Java (Servlets)
* HTML, CSS, JavaScript
* Spotify Web API
* Apache Tomcat


##  Note

* Requires Spotify access token
* Backend must be running for full functionality
